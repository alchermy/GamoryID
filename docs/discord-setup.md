# ตั้งค่า Discord สำหรับ GamoryID

GamoryID ใช้ Discord HTTP Interactions จึงไม่ต้องเปิดโปรแกรมบอทค้างไว้ และใช้งานบน Shared Hosting ที่รองรับ Laravel, HTTPS, outbound HTTPS, cron และ PHP CLI ได้

## ค่าที่ต้องเตรียมใน Production

สร้าง Application ที่ Discord Developer Portal แล้วใส่ค่าเหล่านี้ใน `.env` ของ backend:

```env
DISCORD_APPLICATION_ID=
DISCORD_PUBLIC_KEY=
DISCORD_BOT_TOKEN=
DISCORD_TEST_BYPASS=false
```

ตั้ง Interactions Endpoint URL เป็น:

```text
https://โดเมนของคุณ/api/v1/discord/interactions
```

ค่าทั้งสามต้องอยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามใส่ใน React, Git, log หรือส่งให้ร้านค้า

## Flow สำหรับพ่อค้า

1. เปิดเมนู **Discord** ใน GamoryID
2. กด **เริ่มเชื่อมต่อ Discord**
3. กด **เพิ่มบอทใน Discord** แล้วเลือกเซิร์ฟเวอร์ของร้าน
4. คัดลอกคำสั่ง `/ร้าน ตั้งค่า รหัส` ไปวางใน Discord ภายใน 10 นาที คำสั่งนี้ใช้สำหรับเชื่อมร้านครั้งแรกเท่านั้น
5. กลับมากด **ตรวจสอบสถานะ**
6. กด **ซิงก์ห้องและคำสั่ง** เพื่ออัปเดตคำสั่งล่าสุดและสร้างหมวด **จัดการร้าน GamoryID** พร้อมห้อง `คำสั่งทั่วไป`, `ระบบและข้อผิดพลาด`, `รายการขาย`, `รายการจอง` และ `คลังไอดี` โดยกดซ้ำได้โดยไม่สร้างห้องซ้ำ
7. สมาชิกแต่ละคนสร้างรหัสของตัวเอง แล้วใช้ `/ร้าน เชื่อมบัญชี รหัส` ในห้อง `คำสั่งทั่วไป`
8. ใช้คำสั่ง `/ร้าน ช่วยเหลือ` ในห้อง `คำสั่งทั่วไป` เพื่อดูเฉพาะคำสั่งที่บัญชีของตนมีสิทธิ์ใช้งาน

ทุกคำตอบเป็นข้อความส่วนตัวเฉพาะผู้สั่งคำสั่ง และคำสั่งค้นหา/รายการไม่รวมชื่อผู้ใช้ รหัสผ่าน ต้นทุน หรือโน้ตภายใน

## คำสั่งจัดการร้าน

| คำสั่ง | ใช้ทำอะไร | สิทธิ์พนักงานที่ต้องมี |
| --- | --- | --- |
| `/ร้าน สรุป` | ดูจำนวนพร้อมขาย ถูกจอง ยอดขายเดือนนี้ และกำไรเมื่อมีสิทธิ์ดูต้นทุน/กำไร | สมาชิกที่เชื่อมบัญชีทุกคน |
| `/ร้าน รายการ` | ดูรายการล่าสุด กรองสถานะ และเลือกจำนวน 1–10 รายการ | จัดการสต็อก หรือ จองและขาย |
| `/ร้าน จอง` | จองไอดี ระบุลูกค้า ระยะเวลา และโน้ตได้ | จองและขาย |
| `/ร้าน ยกเลิกจอง` | ยกเลิกการจองและคืนสถานะพร้อมขาย | จองและขาย |
| `/ร้าน ปิดการขาย` | บันทึกลูกค้า ราคา ช่องทางติดต่อ ประกัน และรายละเอียดการขาย | จองและขาย |
| `/ร้าน โน้ต` | บันทึกโน้ตเตือนความจำภายในทีมไว้กับไอดี | จัดการสต็อก หรือ จองและขาย |
| `/ร้าน เพิ่มไอดี` | เพิ่ม Riot ID แรงก์ เลเวล ต้นทุน ราคา รายละเอียด และโน้ต | จัดการสต็อก |
| `/ร้าน ช่วยเหลือ` | ดูเฉพาะคำสั่งที่บัญชีมีสิทธิ์ใช้ | สมาชิกที่เชื่อมบัญชีทุกคน |

ยังมี `/ร้าน ค้นหา` สำหรับค้นหาด้วยแท็ก, `/ร้าน ตั้งค่า` สำหรับเชื่อมร้านครั้งแรก และ `/ร้าน เชื่อมบัญชี` สำหรับเชื่อมสมาชิก

คำสั่ง `/ร้าน เพิ่มไอดี` ไม่รับ Username หรือ Password ผ่าน Discord ให้เพิ่มข้อมูลลับจากหน้ารายละเอียดไอดีบนเว็บเท่านั้น

## สิทธิ์ของพนักงาน

1. เจ้าของร้านเปิดเมนู **ทีมและสิทธิ์** ใน GamoryID
2. เชิญหรือเลือกพนักงาน แล้วเปิดสิทธิ์ **จัดการสต็อก**, **จองและขาย** และ **ดูต้นทุนและกำไร** ตามหน้าที่
3. พนักงานสร้างรหัสเชื่อมบัญชีจากหน้า Discord ของร้าน แล้วใช้ `/ร้าน เชื่อมบัญชี รหัส` ในห้อง `คำสั่งทั่วไป`
4. บอทอ่านสิทธิ์ล่าสุดจาก GamoryID ทุกครั้ง จึงไม่ต้องตั้ง Discord Role เพิ่ม และเมื่อเจ้าของปิดสิทธิ์หรือนำพนักงานออก คำสั่งนั้นจะใช้ไม่ได้ทันที

สิทธิ์ **จัดการ Discord** ใช้สำหรับเชื่อมเซิร์ฟเวอร์ สร้างห้อง และตั้งค่าห้องแจ้งเตือนเท่านั้น ไม่ทำให้พนักงานมีสิทธิ์แก้สต็อกหรือขายสินค้าโดยอัตโนมัติ

ระบบส่งการแจ้งเตือนเมื่อเพิ่มไอดี จอง ยกเลิกจอง และปิดการขายผ่านคิว `notifications` โดยไม่แนบข้อมูลเข้าสู่ระบบ ต้นทุน ข้อมูลลูกค้า หรือโน้ตภายใน บน Shared Hosting ให้ตั้ง cron เรียกคำสั่งนี้ทุกนาที:

```text
php artisan queue:work --queue=notifications,default --stop-when-empty
```

เมื่อย้ายไป VPS ให้ใช้ Supervisor ดูแล queue worker แทน cron เพื่อให้แจ้งเตือนเร็วขึ้น

## ทดสอบในเครื่องโดยยังไม่มีคีย์

ใช้เฉพาะ local/testing:

```env
DISCORD_TEST_BYPASS=true
```

จากหน้า Discord กด **ทดลองด้วยโหมดจำลอง** ระบบจะสร้างเซิร์ฟเวอร์ ห้องแจ้งเตือน และบัญชีที่เชื่อมไว้สำหรับตรวจ UI โดยไม่เรียก Discord จริง ก่อนขึ้น Production ต้องเปลี่ยนกลับเป็น `false` เสมอ
