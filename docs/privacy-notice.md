## 2. บทบาท: ผู้ควบคุม vs ผู้ประมวลผล

- **ข้อมูลบัญชีผู้ใช้และการเรียกเก็บเงิน** (ชื่อ อีเมล การชำระเงิน การใช้งานระบบ) — GamoryID เป็น
  **ผู้ควบคุมข้อมูล**
- **ข้อมูลลูกค้าของร้านที่เจ้าของร้าน/พนักงานบันทึกเข้าระบบ** — เจ้าของร้านเป็น **ผู้ควบคุมข้อมูล**
  และ GamoryID เป็น **ผู้ประมวลผลข้อมูล** ตามคำสั่งของร้าน เจ้าของร้านรับผิดชอบการมีฐานทางกฎหมาย
  และการแจ้งนโยบายความเป็นส่วนตัวต่อลูกค้าของตน หน้าที่ของ GamoryID ในฐานะผู้ประมวลผลเป็นไปตาม
  [ข้อกำหนดการใช้บริการ](/terms) หัวข้อ "บทบาทด้านข้อมูลส่วนบุคคล (PDPA)"
- ข้อมูลของลูกค้าปลายทางกลุ่มนี้ GamoryID ได้รับจากการที่ร้านบันทึกหรือนำเข้าสู่ระบบ ไม่ได้เก็บ
  จากเจ้าของข้อมูลโดยตรง หากคุณเป็นลูกค้าของร้านและต้องการใช้สิทธิเกี่ยวกับข้อมูลของคุณ โปรด
  ติดต่อร้านที่คุณทำรายการด้วยเป็นลำดับแรก ในฐานะผู้ควบคุมข้อมูลของคุณ

## 4. วัตถุประสงค์และฐานการประมวลผล (PDPA)

| วัตถุประสงค์ | ฐานทางกฎหมาย |
|---|---|
| ให้บริการจัดการสต็อก/จอง/ขาย, จัดการบัญชีและร้าน | การปฏิบัติตามสัญญา |
| ยืนยันตัวตน, รักษาความปลอดภัย, ป้องกันการฉ้อโกง, บันทึกกิจกรรมเพื่อตรวจสอบย้อนหลัง | ประโยชน์โดยชอบด้วยกฎหมาย |
| ตรวจสอบการชำระเงิน (ส่งภาพสลิปให้ SlipOK) | การปฏิบัติตามสัญญา |
| ส่งอีเมลยืนยัน/แจ้งเตือนเกี่ยวกับบริการและแพ็กเกจ | การปฏิบัติตามสัญญา / ประโยชน์โดยชอบด้วยกฎหมาย |
| ส่งแจ้งเตือนเข้า Discord ของร้าน | ความยินยอม (ร้านเลือกเชื่อมต่อเอง) |
| เก็บเอกสาร/รายการทางการเงินเพื่อบัญชีและภาษี | การปฏิบัติหน้าที่ตามกฎหมาย |

เราไม่ใช้ข้อมูลส่วนบุคคลเพื่อการตลาดของบุคคลที่สาม และไม่ขาย/ให้เช่าข้อมูล

## 5. การเปิดเผยต่อบุคคลที่สาม

- **SlipOK** — ส่งภาพสลิปเพื่อตรวจสอบการโอน
- **ผู้ให้บริการอีเมล (SMTP)** — ส่งอีเมลยืนยัน/แจ้งเตือน
- **Discord** — เฉพาะเมื่อร้านเชื่อมต่อเอง; **ไม่ส่ง** ข้อมูลเข้าสู่ระบบของไอดี ต้นทุน ข้อมูลติดต่อลูกค้า หรือโน้ตภายใน
- **ผู้ให้บริการโครงสร้างพื้นฐาน (โฮสติ้ง/คลาวด์)** — จัดเก็บและรันระบบ
- หน่วยงานรัฐหรือศาล — เมื่อมีคำสั่งที่ชอบด้วยกฎหมาย
- ผู้รับโอนกิจการ — กรณีมีการควบรวม/โอนกิจการ โดยจะแจ้งให้ทราบ

## 6. การโอนข้อมูลไปต่างประเทศ

ผู้ให้บริการภายนอกบางราย (เช่น Discord, ผู้ให้บริการอีเมล, ผู้ให้บริการคลาวด์) อาจประมวลผล
หรือจัดเก็บข้อมูลนอกประเทศไทย เราเลือกใช้ผู้ให้บริการที่มีมาตรฐานคุ้มครองข้อมูลที่เหมาะสม
และจำกัดการส่งข้อมูลเท่าที่จำเป็นต่อวัตถุประสงค์นั้น ๆ

## 9. ความปลอดภัย

- ข้อมูลเข้าสู่ระบบของไอดีเข้ารหัส AES-256-GCM ด้วยคีย์ที่เก็บนอกฐานข้อมูล; ต้องยืนยันตัวตนซ้ำก่อนดู
- Session แบบ HttpOnly cookie + CSRF + rate limiting; เจ้าของนำอุปกรณ์อื่นออกจากระบบได้; รองรับ 2FA
- ไฟล์สลิป/รูปสินค้า/ไฟล์นำเข้า เป็น private object เข้าถึงผ่าน signed URL
- ระบบ multi-tenant: ทุก query ผูก `shop_id` + policy/scope ป้องกันการเข้าถึงข้ามร้าน

## 10. การแจ้งเหตุละเมิดข้อมูลส่วนบุคคล

หากเกิดเหตุละเมิดข้อมูลส่วนบุคคลที่เสี่ยงต่อสิทธิและเสรีภาพของบุคคล เราจะแจ้งสำนักงานคณะกรรมการ
คุ้มครองข้อมูลส่วนบุคคล **ภายใน 72 ชั่วโมง** นับแต่ทราบเหตุเท่าที่สามารถทำได้ และจะแจ้งเจ้าของข้อมูล
ที่ได้รับผลกระทบเมื่อมีความเสี่ยงสูง

## 11. คุกกี้

แอปสำหรับพ่อค้าใช้ **คุกกี้ที่จำเป็น** สำหรับการเข้าสู่ระบบ (session แบบ HttpOnly) และความปลอดภัย
(CSRF) เท่านั้น เราไม่ใช้คุกกี้เพื่อการโฆษณาหรือติดตามข้ามเว็บไซต์ เว็บไซต์แนะนำบริการอาจเก็บ
ค่าการตั้งค่าเล็กน้อยในเบราว์เซอร์ของคุณ (localStorage) เพื่อความสะดวกในการแสดงผล

## 12. ผู้เยาว์

ผู้เยาว์ที่ทำนิติกรรมเองไม่ได้ หากพบว่ามีการเก็บข้อมูลดังกล่าวโดยไม่มีฐานที่ถูกต้อง เราจะลบออก
