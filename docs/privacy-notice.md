# นโยบายความเป็นส่วนตัว · GamoryID

> ฉบับร่างสำหรับช่วง pilot — ปรับปรุงล่าสุด 2 กันยายน 2026
> ก่อนเปิดบริการวงกว้างต้องให้ที่ปรึกษากฎหมายตรวจทานตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)

## 1. ข้อมูลที่เก็บ

| กลุ่ม | ตัวอย่างข้อมูล | ที่มา |
|---|---|---|
| บัญชีผู้ใช้ | ชื่อ, อีเมล, รหัสผ่าน (แฮช), IP/อุปกรณ์ที่เข้าใช้งาน | ผู้ใช้กรอกตอนสมัคร / เข้าสู่ระบบ |
| ข้อมูลร้าน | ชื่อร้าน, ช่องทางติดต่อ, แพ็กเกจ, ยอดเครดิต | เจ้าของร้านกรอก |
| คลังสินค้า | รายละเอียดไอดี, ต้นทุน/ราคา, ข้อมูลเข้าสู่ระบบของไอดี (เข้ารหัส AES-256-GCM) | เจ้าของร้าน/พนักงานกรอกหรือนำเข้า |
| ลูกค้าของร้าน | ชื่อ, เบอร์โทร, LINE ID, Facebook | เจ้าของร้าน/พนักงานบันทึกตอนจอง/ขาย |
| ธุรกรรม | รายการขาย, กำไร, การจอง, สลิปเติมเครดิต, ประวัติเครดิต | ระบบบันทึกอัตโนมัติ |
| บันทึกกิจกรรม | ใคร ทำอะไร เมื่อไร จาก IP ใด (ไม่บันทึกค่าความลับ) | ระบบบันทึกอัตโนมัติ |

## 2. วัตถุประสงค์

ให้บริการจัดการสต็อกและงานขาย, ยืนยันตัวตน, ตรวจสอบการชำระเงิน (ผ่าน SlipOK), แจ้งเตือน (อีเมล/Discord), ตรวจสอบย้อนหลังเพื่อความปลอดภัยของร้าน และปฏิบัติตามกฎหมาย

## 3. การเปิดเผยต่อบุคคลที่สาม

- **SlipOK** — ส่งภาพสลิปเพื่อตรวจสอบการโอน
- **ผู้ให้บริการอีเมล (SMTP)** — ส่งอีเมลยืนยัน/แจ้งเตือน
- **Discord** — เฉพาะเมื่อร้านเชื่อมต่อเอง; ไม่ส่งข้อมูลเข้าสู่ระบบ ต้นทุน ข้อมูลติดต่อลูกค้า หรือโน้ตภายใน
- ไม่ขายหรือให้เช่าข้อมูลส่วนบุคคลแก่บุคคลที่สามเพื่อการตลาด

## 4. ระยะเวลาเก็บรักษา (ตั้งค่าที่ `config/privacy.php`)

| ข้อมูล | ค่าเริ่มต้น | เมื่อครบกำหนด |
|---|---|---|
| ข้อมูลติดต่อลูกค้าที่ไม่มีความเคลื่อนไหว | 24 เดือน | ลบชื่อ/เบอร์/LINE/Facebook อัตโนมัติ (เก็บประวัติการขายแบบไม่ระบุตัวตน) |
| บันทึกกิจกรรม | 24 เดือน | ลบ |
| ประวัติงานนำเข้า + error รายแถว | 90 วัน | ลบ |
| ไฟล์ภาพสลิป | 180 วัน | ลบไฟล์ (เก็บรายการชำระเงินไว้เป็นหลักฐานทางบัญชี) |
| ไฟล์นำเข้า (CSV/Excel) | ลบทันที | ลบหลังประมวลผลเสร็จ |

`DataRetentionLifecycle` รันทุกวันเวลา 03:20 น. ตาม schedule

## 5. สิทธิของเจ้าของข้อมูล

- **ขอลบข้อมูลติดต่อลูกค้า** — เจ้าของร้าน/ผู้มีสิทธิ์ `team.manage` กดลบได้จากหน้า "ลูกค้า" (`DELETE /api/v1/customers/{id}`) ระบบจะลบ ชื่อ/เบอร์/LINE/Facebook ทันที และเก็บเฉพาะประวัติการขายแบบไม่ระบุตัวตน
- **ขอสำเนาข้อมูล** — เจ้าของร้านส่งออกข้อมูลคลังเป็น CSV ได้ (`GET /api/v1/export/inventory.csv`) การส่งออกข้อมูลลูกค้า/การขายฉบับเต็มติดต่อทีมงาน
- **ขอลบบัญชี/ร้านทั้งหมด** — ติดต่อทีมงาน; Super Admin ระงับ/ลบร้านได้ (soft delete พร้อม audit)

## 6. ความปลอดภัย

- ข้อมูลเข้าสู่ระบบของไอดีเข้ารหัส AES-256-GCM ด้วยคีย์ที่เก็บนอกฐานข้อมูล; ต้องยืนยันตัวตนซ้ำก่อนดู
- Session แบบ HttpOnly cookie + CSRF + rate limiting; เจ้าของนำอุปกรณ์อื่นออกจากระบบได้
- ไฟล์สลิป/รูปสินค้า/ไฟล์นำเข้า เป็น private object เข้าถึงผ่าน signed URL
- Multi-tenant: ทุก query ผูก `shop_id` + policy/scope ป้องกันการเข้าถึงข้ามร้าน

## 7. ติดต่อ

ระบุอีเมล/ช่องทางของผู้ควบคุมข้อมูล (Data Controller) ก่อนเปิดบริการจริง
